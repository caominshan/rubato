# Hey Tablo Agent v0.1 评测报告

## 1. 评测目标

本报告验证的不是“模型回答看起来像不像真人”，而是 MVP 的关键承诺是否成立：能从真实字幕中检索、能说明来源、模型失败时不伪造结果、收到负反馈后不重复推荐。

评测日期：2026-09-24  
数据版本：29 期节目、500 条字幕片段、390 条已验证片段  
自动化环境：Node.js 22、Vitest、Next.js production build

## 2. 评测维度与结果

| 维度 | 测量方式 | 结果 |
|---|---|---:|
| Schema 完整性 | 500 条字幕全部通过 Zod Schema | 500 / 500 |
| 精确检索 | “mentally bulletproof”命中预期原文与集数 | 通过 |
| 跨语言检索 | 中文“失恋后想被陪伴”命中相关英文字幕 | 通过 |
| 来源过滤 | `verifiedOnly=true` 后结果全部已验证 | 通过 |
| 推荐多样性 | 3 条推荐来自 3 个不同 episode | 通过 |
| 多轮去重 | 第二轮 ID 与第一轮无交集 | 通过 |
| 输入防御 | 非法请求在调用 Agent 前返回 400 | 通过 |
| 降级能力 | 无模型密钥时仍返回确定性检索结果 | 通过 |
| 信息不足 | “随便”触发澄清且工具调用数为 0 | 通过 |
| 工程质量 | TypeScript、16 tests、production build | 全部通过 |
| 指标口径 | 点击、来源打开、负反馈和反馈后播放计算 | 4 / 4 通过 |

## 3. 16 个自动化测试覆盖

### 检索与工具：7 个

1. 字幕 Schema 完整性。
2. 精确英文短语检索。
3. 中文需求到英文字幕的查询扩展。
4. 已验证来源过滤。
5. 单集元数据与上下文片段获取。
6. 三条推荐的来源与集数多样性。
7. 重新规划时强制排除历史片段。

### API 与 Agent：5 个

8. 非法请求被拒绝。
9. 无模型密钥时透明降级。
10. Qwen 配置缺失时返回正确凭证提示。
11. 信息不足时先澄清、不调用工具。
12. “太说教”反馈更新约束、进入第二轮且结果不重复。

### 用户反馈分析：4 个

13. 从演示事件正确计算四个核心产品指标。
14. 同一轮重复点击不会重复计入点击率。
15. 没有本机事件时稳定返回零值，而不是 `NaN`。
16. 正确生成四类负反馈分布和交互漏斗。

## 4. 关键质量指标

```text
自动化测试通过率       16 / 16 = 100%
字幕 Schema 通过率    500 / 500 = 100%
来源验证数据覆盖率     390 / 500 = 78%
关键降级路径通过率       2 / 2 = 100%
多轮去重场景通过率       1 / 1 = 100%
```

“来源验证数据覆盖率 78%”不代表推荐准确率为 78%。它只说明当前语料中有 390 条完成了来源验证；未验证片段在界面中会明确标记，正式引用前需要人工复核。

## 5. 错误与降级矩阵

| 情况 | 系统行为 | 是否保留可用结果 |
|---|---|---|
| 输入少于 2 字或超过 300 字 | 返回 `invalid_request` | 否，要求用户修改输入 |
| JSON 格式错误 | 返回 `invalid_json` | 否 |
| 未配置模型密钥 | 本地 MiniSearch 降级 | 是 |
| Agent 未成功调用检索工具 | 本地检索降级并记录错误 | 是 |
| Qwen/OpenAI 请求失败 | 本地检索降级并标记低置信度 | 是 |
| 反馈重新规划失败 | 保留上一轮结果并显示局部错误 | 是 |
| 外部封面加载失败 | 切换本地默认封面 | 是 |

## 6. 结论

当前版本达到面试 Demo 的质量门槛：核心链路可运行、关键约束可测试、失败路径可降级、推荐结果可追溯。它还不能证明线上真实用户满意度，也不能替代人工内容审核。

下一步应补充：20–50 条人工标注查询集、Top-3 相关率、二次播放率、反馈后满意度变化、P50/P95 延迟和真实移动端端到端测试。
